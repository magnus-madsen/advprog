# Advanced Programming

Welcome to the webpage for the _Logic Programming_ module, part of the _Advanced
Topics in Programming Languages Theory_ (ATPLT) course at Aarhus University.

This module is taught by [Magnus Madsen](https://cs.au.dk/~magnusm/)
(magnusm@cs.au.dk).

All material in this course is freely available under the Apache 2.0 license.

You can edit this course! The source for the book and slides is available on
[GitHub](https://github.com/magnus-madsen/advprog)!
